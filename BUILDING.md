# Requisiti di compilazione

Android Gradle Plugin 8.7.3 richiede JDK 17. Il progetto usa compileSdk 35, minSdk 26 e targetSdk 33. Non servono NDK, account, chiavi di firma o dipendenze scaricate dall'app in esecuzione.

Per un APK distribuibile pubblicamente è necessario compilare una variante release e firmarla con una chiave privata conservata dall'autore. L'APK debug generato da Android Studio è sufficiente per installare e usare l'app sul proprio telefono.
